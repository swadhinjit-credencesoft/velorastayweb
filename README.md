# Y Hotels Signature

Website for Y Hotels Signature, Mangalam Tower, Sarbahal Road, Marwari Para, Jharsuguda, Odisha 768201.

Built with Next.js 14 App Router, TypeScript, SCSS Modules and Redux Toolkit.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Property data

Room inventory, rates and contact details are maintained locally in `src/data`. The site does not currently connect to a booking engine. Contact the hotel to confirm dates, room availability and meal-plan pricing.
